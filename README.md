- Что происходит с загрузкой CPU при увеличении количества одновременно работающих потоков? 

При увеличении количества потоков загрузка процессора возрастает, так как вычисления распределяются между несколькими логическими процессорами. Мой процессор имеет 4 логических процессора, поэтому при запуске 1 потока загружается примерно четверть процессора, при двух - половина, при 4 загрузка достигает 100%.

- Почему после некоторого количества потоков дальнейшее увеличение не обязательно продолжает заметно повышать загрузку? 

Это связано с тем, что количество логических процессоров ограничено. Как только количество потоков превышает количество доступных ядер, ОС начинает переключаться между потоками. Загрузка уже достигает 100% и не может стать выше, а дополнительные потоки лишь увеличивают накладные расходы на переключение.

В моем случае количество физических ядер и логических процессоров совпадает. Но если была бы технология Hyper-Threading/SMT, то одно физическое ядро представлялось бы операционной системе как два логических процессора. Это сделано для того, чтобы эффективнее использовать ресурсы ядра: пока один поток ждет выполнения медленной операции, ядро может параллельно выполнять команды второго потока

# Итоговый вопрос

Это не является противоречием, потому что Environment.ProcessorCount показывает не количество "железа" (физических ядер), а количество логических процессоров, которые ОС предоставляет программам для выполнения вычислений. Благодаря Hyper-Threading/SMT одно физическое ядро представляется системе как два логических.

# Контрольные вопросы

### 1. Что показывает Environment.ProcessorCount? 

Количество логических процессоров

### 2. Чем физическое ядро отличается от логического процессора? 

Физическое ядро - реальный компонент. Логический процессор - это "виртуальный" поток, который видит ОС благодаря технологиям Hyper-Threading, позволяющим одному ядру выполнять два потока одновременно.

### 3. Почему увеличение количества потоков может увеличить загрузку CPU? 

Потоки распределяются по разным ядрам. Чем больше ядер задействовано, тем выше общая загрузка процессора.

### 4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти? 

Ядер физически ограниченное количство. Когда все ядра заняты (загрузка 100%), новые потоки просто встают в очередь, и ОС переключает их между собой.

### 5. Почему частота процессора может изменяться во время работы? 

Процессор экономит энергию и снижает частоту в простое, а при нагрузке автоматически повышает её, чтобы быстрее выполнить вычисления.
